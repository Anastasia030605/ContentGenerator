# Content Generator для Telegram каналов

Автоматизированный сервис для создания контента в стиле вашего Telegram канала с использованием RAG (Retrieval-Augmented Generation).

## Возможности

- **Сбор данных из Telegram**: Автоматический сбор постов и метрик (просмотры, реакции, пересылки)
- **Анализ популярности**: Определение успешных паттернов контента, оптимального времени публикации
- **Контент-планирование**: Автоматическое создание контент-плана на N недель с помощью LLM
- **RAG генерация**: Генерация постов в стиле канала на основе векторного поиска и LLM
- **Поддержка OpenAI и Anthropic**: Выбор между GPT и Claude для генерации

## Установка

### 1. Клонирование и установка зависимостей

```bash
# Создание виртуального окружения
python -m venv .venv

# Активация (Windows)
.venv\Scripts\activate

# Активация (Linux/Mac)
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Получение Telegram API credentials

1. Перейдите на https://my.telegram.org/apps
2. Войдите с помощью вашего номера телефона
3. Создайте новое приложение
4. Сохраните `api_id` и `api_hash`

### 3. Получение API ключа для LLM

**Вариант A: OpenAI**
1. Зарегистрируйтесь на https://platform.openai.com/
2. Создайте API ключ в разделе API Keys
3. Пополните баланс (минимум $5)

**Вариант B: Anthropic**
1. Зарегистрируйтесь на https://console.anthropic.com/
2. Создайте API ключ
3. Пополните баланс

### 4. Настройка конфигурации

```bash
# Скопируйте пример конфигурации
cp .env.example .env

# Отредактируйте .env файл
notepad .env  # Windows
nano .env     # Linux/Mac
```

Заполните все обязательные поля:

```env
# Telegram
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=your_hash
TELEGRAM_PHONE=+79991234567
TELEGRAM_CHANNEL_USERNAME=your_channel

# AI Provider (openai или anthropic)
AI_PROVIDER=openai

# OpenAI
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini

# Или Anthropic
ANTHROPIC_API_KEY=sk-ant-...
ANTHROPIC_MODEL=claude-3-5-sonnet-20241022
```

## Использование

### Быстрый старт (Полный пайплайн)

Запустите весь процесс одной командой:

```bash
python main.py pipeline --limit 100
```

Это выполнит все шаги:
1. Соберет 100 последних постов
2. Проанализирует канал
3. Проиндексирует посты для RAG
4. Создаст контент-план на 2 недели
5. Сгенерирует посты по плану

### Пошаговое использование

#### 1. Сбор постов из канала

```bash
# Собрать последние 50 постов
python main.py collect --limit 50

# Собрать посты за последние 30 дней
python main.py collect --days 30

# Собрать 200 постов
python main.py collect --limit 200
```

При первом запуске Telegram попросит ввести код подтверждения, отправленный в приложение.

#### 2. Анализ канала

```bash
python main.py analyze
```

Покажет:
- Статистику по просмотрам и engagement
- Лучшее время для публикации
- Топ-5 постов
- Популярные слова и темы
- Рекомендации по контенту

#### 3. Индексация для RAG

```bash
python main.py index
```

Создаст векторное хранилище ChromaDB с эмбеддингами постов для поиска похожего контента.

#### 4. Создание контент-плана

```bash
# План на 4 недели, 7 постов в неделю
python main.py plan --weeks 4 --posts-per-week 7

# С дополнительными инструкциями
python main.py plan --weeks 2 --posts-per-week 5 --instructions "Фокус на образовательный контент"
```

Результат сохраняется в `data/content_plan_YYYYMMDD_HHMMSS.json`

#### 5. Генерация постов

```bash
# Генерация по последнему контент-плану
python main.py generate

# Генерация по конкретному плану
python main.py generate --plan data/content_plan_20240115_120000.json

# С указанием файла для сохранения
python main.py generate --output my_posts.json
```

#### 6. Генерация одного поста

```bash
# Текстовый пост
python main.py generate-one --topic "Утренняя мотивация"

# Пост с фото
python main.py generate-one --topic "Инфографика о продуктивности" --format photo

# Видео пост
python main.py generate-one --topic "Обзор новых функций" --format video
```

## Веб-интерфейс

После установки зависимостей и настройки `.env` вы можете запустить web UI:

```bash
uvicorn src.api:app --reload
```

Откройте браузер и перейдите на:

```bash
http://127.0.0.1:8000/
```

Если у вас пока нет реального Telegram-канала или API-ключей, используйте кнопку «Заполнить демонстрационными постами». Это добавит тестовые посты в базу, и вы сможете:

- посмотреть статус данных
- создать контент-план
- сгенерировать пример поста

В списке провайдеров доступен режим `Демо`, который работает без внешнего LLM API.

## Продвинутое использование

### Программный доступ

```python
from src.telegram_client import TelegramDataCollector
from src.analyzer import PostAnalyzer
from src.rag_generator import RAGPostGenerator

# Сбор постов
collector = TelegramDataCollector()
await collector.connect()
posts = await collector.collect_posts(limit=100)
collector.save_posts(posts)
await collector.disconnect()

# Анализ
analyzer = PostAnalyzer(posts)
insights = analyzer.generate_insights()
print(insights['summary'])

# Генерация
generator = RAGPostGenerator()
generator.index_posts(posts)
post = generator.generate_post(
    topic="Новогодние скидки",
    format_type="photo"
)
print(post)
```

### Обновление метрик существующих постов

```python
await collector.connect()
await collector.update_metrics()  # Обновить все посты
await collector.disconnect()
```

### Поиск похожих постов

```python
generator = RAGPostGenerator()
generator.load_collection()

similar = generator.find_similar_posts(
    query="мотивация успех",
    n_results=5,
    min_engagement=0.02
)

for post in similar:
    print(f"{post['text'][:100]}... (ER: {post['engagement_rate']:.2%})")
```

## Настройки

Все настройки в `.env` файле:

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `AI_PROVIDER` | Провайдер LLM: openai или anthropic | openai |
| `OPENAI_MODEL` | Модель OpenAI | gpt-4o-mini |
| `ANTHROPIC_MODEL` | Модель Anthropic | claude-3-5-sonnet-20241022 |
| `EMBEDDING_MODEL` | Модель для эмбеддингов | paraphrase-multilingual-MiniLM-L12-v2 |
| `CONTENT_PLAN_WEEKS` | Недель в контент-плане | 4 |
| `POSTS_PER_WEEK` | Постов в неделю | 7 |
| `CHROMA_PERSIST_DIRECTORY` | Папка для ChromaDB | data/chroma |

## Troubleshooting

### Ошибка авторизации Telegram

```
FloodWaitError: A wait of X seconds is required
```

Решение: Подождите указанное время перед повторной попыткой.

### Ошибка ChromaDB

```
Collection not found
```

Решение: Запустите `python main.py index` для индексации постов.

### Ошибка API ключа

```
AuthenticationError: Incorrect API key
```

Решение: Проверьте правильность API ключа в `.env` файле.

### Нет постов с текстом

```
ValueError: Нет постов с текстом для индексации
```

Решение: Канал содержит только медиа без текста. Соберите больше постов или используйте другой канал.

## Рекомендации

1. **Качество данных**: Собирайте минимум 50-100 постов для качественного анализа
2. **Обновление метрик**: Регулярно обновляйте метрики для актуальности анализа
3. **Проверка постов**: Всегда проверяйте сгенерированные посты перед публикацией
4. **Разнообразие**: Используйте параметр `instructions` в контент-плане для контроля тематики
5. **Тестирование**: Начните с малого плана (1-2 недели) для оценки качества
